## 领取流程和限制

1. 用户手动登录正确角色并进入“太守奖励”邮件详情。本期 Pipeline 只识别该主题，不自动从主城导航。
2. Pipeline 先匹配详情标题，再匹配绿色领取按钮，并点击当前识别框。Maa 原生 Pipeline 显式 `repeat=1`、`max_hit=1`；静态检查限定两个模板识别节点、一条线性边和一个 Click。
3. 成功状态使用真实领取后弹出的“点击任意区域关闭”特征。奖励动画会导致标题模板分数波动，所以不使用动画文字作为唯一成功判据。按钮也会保持在背景但变灰；实机成功帧得分 0.923，因此可领阈值设为 0.97。
4. 成功弹窗关闭前再次运行会识别 `already_claimed`，返回 `nothing_to_claim`，不提交 Pipeline、不发输入。若页面/状态素材不能命中，则保持 needs_attention，不重试。

相关实机证据见 `reports/phase1-report.md` 的领取前后及重复运行工件链接。原始截图保存在本地 `artifacts/runs/`，未复制到版本管理；回归测试按本机工件路径读取，缺少本地样本时会 skip，不会伪造截图。
